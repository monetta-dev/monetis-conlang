# 1. 言語の基本思想

この言語では、**音・文字・意味を完全に恣意的な対応にしない**。

最古層の基本語彙は、人間が物体に対して持つ**色彩イメージ**をもとに作られる。

基本的な生成過程は、

**色 → 子音 → 原始的な具体概念 → 複合概念 → 派生概念 → 抽象・現代概念**

となる。

例えば、

**白 → sh → 骨**

という対応を持つ。

ただし、

**骨 → 核心**

のような抽象化を単なる連想によって直接行うことは避ける。

「骨の構造的性質」「支持するもの」「物事を成立させる構造」といった中間概念を、複合語・接辞・派生規則によって明示的に構築する。

そのため、現代的・抽象的な単語であっても、可能な限りその語の**概念的な系譜**を遡れることを目指す。

---

# 2. 色彩と基本子音

現在、11種類の色を基本カテゴリーとしている。

| 色 | 基本子音 | 原始語彙 |
|---|---|---|
| 白 | **sh** /ʃ/ | 骨 |
| 黒 | **m** /m/ | 木炭 |
| 赤 | **v** /v/ | 血 |
| 黄 | **ch** /tʃ/ | 果実 |
| 緑 | **k** /k/ | 草 |
| 青 | **l** /l/ | 空 |
| 茶 | **j** /ʝ/ | 木の枝 |
| 紫 | **th** /θ/ | 花 |
| ピンク | **t** /t/ | 肉 |
| オレンジ | **n** /n/ | 火打石 |
| 灰 | **z** /z/ | 石 |

これらは単なる「色の名前の頭文字」ではない。

例えば **v** は「赤」を表す子音であると同時に、最古層では赤を代表する具体物である**血**と結び付いている。

したがって後世では、

**血 → 身体 → 生命 → ……**

のような意味ネットワークが形成される可能性がある。

ただし、このような意味拡張には可能な限り明示的な派生規則を用いる。

# 3. 語彙生成

語彙は原則として、少数の原始語彙から構築する。

## Level 0 — 色

例：

**白**

↓

## Level 1 — 原始具体語

**sh = 骨**

↓

## Level 2 — 基本複合語

複数の原始語根を組み合わせて、新しい具体概念を作る。

↓

## Level 3 — 派生語

接頭辞・接尾辞によって、

- 性質
- 状態
- 動作
- 変化
- 集合
- 場所
- 主体
- 道具

などへ変換する。

↓

## Level 4 — 抽象概念

既存概念を派生規則によって抽象化する。

↓

## Level 5 — 現代概念

科学・技術・社会制度などの複雑な概念を、既存概念の複合と派生によって表現する。

したがって「コンピュータ」などの現代語も、原則として完全に新しい語根を導入するのではなく、既存概念の組み合わせから構築する。

# 4. 母音の設計思想

## 母音音素（2026-10-02 決定）

母音は **a /a/・i /i/・e /e/・o /o/** の4種類とし、すべてで長短を区別する。

| 短母音 | 長母音 |
|---|---|
| /a/ | /aː/ |
| /i/ | /iː/ |
| /e/ | /eː/ |
| /o/ | /oː/ |

母音音素は計8個。/u/ は採用しない。長短は音素的な対立であり、長母音を単なる強調表現として扱わない。

長母音のローマ字表記、強勢、弱化・脱落、母音連続の扱いは今後決定する。試作資料では暫定的に `aa / ii / ee / oo` と表記し、IPAでは /ː/ を用いる。

**母音そのものには強い語彙的意味を持たせない。**

これは意図的な設計である。

子音が語彙体系の意味的な骨格を担うため、

> a = 物体  
> i = 性質  
> u = 動作

のような一対一の意味対応は基本的に採用しない。

母音の主要な役割は、

- 発音可能性の確保
- 子音間の接続
- 音節形成
- 音韻変化
- 接辞形成

である。

これによって、語彙の意味体系を子音側に集中させる。

# 5. CV構造と母音脱落

文字体系は子音＋母音を基本単位とするが、**話し言葉まで単純なCV構造に固定しない**。

歴史的・形態音韻的な規則によって母音が、

- 弱化
- 脱落
- 挿入

する。

その結果、

**CV → CVC → CCV → CCVC**

などの構造を許容する。

特に複合語では母音脱落が起こりやすく、複数の子音が連続することがある。

これにより、文字体系の基本構造を維持しながら、話し言葉が単調なCV列になることを防ぐ。

---

# 6. 子音単独語根

基本語根は**子音 C 単独**でも成立できる。

また、必要に応じて子音そのものが音節核となることも許容する。

特に、

**m / n / l**

などは成節子音として利用できる可能性がある。

したがって、

**C、CC、CVC、CCVC**

なども正規の語形になり得る。

---

# 7. 文字体系

文字体系は独自文字を使用する。

一文字は基本的に、

**上部 = 子音**  
**下部 = 母音**

から構成される。

概念としてはハングルの音節ブロックに近いが、子音部分と母音部分を**縦方向に組み合わせて一文字**とし、それを左から右へ並べる。

```text
┌─────┐
│  C  │
│─────│
│  V  │
└─────┘
```

CまたはVを欠く文字も存在できる。

その場合、該当部分は空になる。

---

# 8. 文字の三段階の高さ

この文字体系最大の特徴の一つとして、文字そのものを置く高さに、

**高位 / 中位 / 低位**

の三段階が存在する。

これは装飾ではなく、形態論的情報を表す。

## 高位

**接頭辞**

## 中位

**語根**

## 低位

**接尾辞**

したがって単語は視覚的に、

```text
 PREFIX
        ROOT
              SUFFIX
```

のような構造を持つ。

複数存在する場合、

```text
 PREFIX PREFIX
               ROOT ROOT
                         SUFFIX SUFFIX
```

のように表記できる。

これにより、単語の内部構造を文字列の輪郭だけからある程度認識できる。

---

# 9. 接辞

語根が基本的にCを中心とするのに対し、接辞は話し言葉でも語根と区別しやすくするため、

**V / VC / VCV**

など、**母音から始まる構造**を基本候補とする。

接頭辞と接尾辞では役割を分ける。

母音の4種類と長短を利用し、接辞は意味・機能を細かく区別して設計してよい（2026-10-02 方針）。少数の接辞に多くの機能をまとめず、例えば部分と分離片、活動と状態変化、道具と容器、集合と結合構造を区別する。具体的な音形・語源・機能は、試作を経て採用する。

## 接頭辞 — 概念の限定

接頭辞は、基本的に既存概念の範囲や見方を変更する。

候補：

- 否定
- 強意
- 弱意
- 大小
- 内 / 外
- 前 / 後
- 時間的位置
- 方向
- 反転

基本的な発想は、

**「どのようなXか」**

を指定すること。

## 接尾辞 — 概念の派生

接尾辞は語根・複合語が属する概念カテゴリーそのものを変換する。

候補：

- 性質化
- 物質化
- 動作化
- 状態化
- 変化「Xになる」
- 使役「Xにする」
- 主体「Xするもの」
- 道具「Xに使うもの」
- 場所「Xが存在する場所」
- 集合
- 部分
- 結果
- 抽象化

したがって、

**接頭辞 = semantic modification**  
**接尾辞 = semantic derivation**

という大まかな役割分担を持つ。

---

# 10. 接辞の歴史

接辞を完全に恣意的な記号として作るのではなく、可能であれば**原始語彙からの文法化**によって説明する。

例えば、

**枝 → 分岐 → 部分 → 部分化接尾辞**

**草 → 群生 → 多数 → 集合接尾辞**

**火 → 変化 → 状態変化接尾辞**

**空 → 空間 → 場所 → 場所接尾辞**

など。

歴史的には独立語だったものが、頻繁な複合によって弱化し、最終的にV / VC / VCV型の接辞になったと考えることができる。

これにより、

**色 → 原始語彙 → 複合語 → 文法化 → 接辞**

という歴史的連続性を作る。

---

# 11. 高・中・低と歴史的発音

文字の三段階は、歴史的には発音上の高低と対応していた可能性がある。

仮説：

**高位文字 → 高い発音**  
**中位文字 → 中程度の発音**  
**低位文字 → 低い発音**

つまり古語では、

**接頭辞 = H**  
**語根 = M**  
**接尾辞 = L**

という韻律的差が存在した。

しかし現代語では、この高さの対立そのものは失われている。

代わりに、かつての高さが子音の発音へ影響した結果、**同一の基本文字が置かれる高さによって異なる子音として発音される**。

これは声調そのものではなく、歴史的な声調・発声差が子音対立へ移行したものとして扱う。

---

# 12. 三段階子音体系

基本的な方向性として、

**高位 = 無声化・強化・強い気流**  
**中位 = 基底音**  
**低位 = 有声化・弱化など**

を想定する。

ただし、すべての子音に完全に同一の規則を機械的に適用する必要はない。

歴史的音韻変化の結果として、子音系列ごとに異なる発達を許容する。

## 無声の中位子音の基本対応（2026-10-02 方針）

**中位が無声音の場合、高位は有気音、低位は有声音**を基本とする。

| 系列 | 高位 | 中位 | 低位 |
|---|---|---|---|
| k | /kʰ/ | /k/ | /g/ |
| t | /tʰ/ | /t/ | /d/ |
| ch | /tʃʰ/ | /tʃ/ | /dʒ/ |
| sh | 有気の方向。具体的実現は要検討 | /ʃ/ | /ʒ/ |
| th | 有気の方向。具体的実現は要検討 | /θ/ | /ð/ |

sh・thは摩擦音なので、高位の具体的な気息の実現・持続時間・音価の記述を別途試作する。中位が有声音であるv・z・jについては、以下の既存の方向性を維持する。m・n・lは無声形を利用する方向だが、三段階全体の対応は要検討。

## 赤系列

基本文字：**v**

**高位:** /f/  
**中位:** /v/  
**低位:** /ʋ/ ～ /w/

概念的には、

**f → v → ʋ/w**

と摩擦が弱くなっていく。

---

## 灰系列

基本文字：**z**

**高位:** /s/  
**中位:** /z/  
**低位:** /ʐ/ ～ /ɻ/

低位は中国語普通話の **r** に近い音を想定する。

---

## 茶系列

基本文字：**j**

**高位:** /ç/  
**中位:** /ʝ/  
**低位:** /ɟ/

転写候補：

**cy → j → gy**

低位 /ɟ/ はハンガリー語 **gy** に近い有声硬口蓋破裂音。

この系列は他系列と異なり、低位で単純に弱化するわけではない。

---

## 紫系列

基本文字：**th**

中位：

**/θ/**

低位は基本対応に従い **/ð/** とする。高位は有気の方向とし、具体的実現を今後決定する。

---

# 13. その他の子音系列

sh・ch・k・tについては第12節の基本対応を用いる。

**m /m/・n /n/・l /l/** は無声鼻音・無声側面音を利用する方向で設計する。ただし高位・低位の完全な対応は要検討。

例：

**/m̥/**  
**/n̥/**  
**/l̥/**

高位にこれらの無声形を置く案は候補。低位の音価は未決定であり、試作02の低位l /ɭ/ は採用済みではない。

したがって、英語・日本語では珍しい子音も積極的に利用できる。

---

# 14. 書記と発音の関係

重要なのは、

**高・中・低という文字位置そのものが、現代語で声調を意味するわけではない**

という点。

歴史的には高さと発音が対応していたが、現代では高さによって子音の音価が変化する。

そのため同じ基本字でも、

```text
      K

K

      K
```

は、それぞれ別の発音を持ち得る。

しかし話者から見れば別文字ではなく、**同じ文字の高位形・中位形・低位形**である。

この仕組みにより、

**書記上の形態論的位置**

と

**話し言葉における子音交替**

が対応する。

# 15. この言語で避けたいもの

設計上、以下は意識的に避ける。

### 単純なCV列への偏り

`katana misora teleku...`

のようにCVが均等に連続する音韻を避ける。

母音脱落や子音連続を積極的に利用する。

### 母音への過剰な意味付与

「aなら物体、iなら性質」のように、すべての音素が意味をコードする体系にはしない。

### 恣意的すぎる抽象化

「骨だから本質」「空だから自由」のような作者の連想だけによる意味ジャンプをなるべく避ける。

複合・接辞・派生規則によって概念形成の過程を示す。

### 過度に規則的な音韻体系

すべての子音について完全な無声/有声対応を作る必要はない。

歴史的な音韻変化による非対称性や例外を許容する。

# 16. 言語全体の情報構造

現時点では、この言語には大きく4つの情報層が存在する。

**① 子音**

→ 色彩を起源とする基本的な意味カテゴリー

**② 母音**

→ 発音・音節形成・接続を担う。語彙的意味は弱い。

**③ 接辞**

→ 概念の限定・派生・抽象化を担う。

**④ 文字の高さ**

→ 接頭辞 / 語根 / 接尾辞という形態論的構造を可視化し、歴史的音韻変化を通じて現代の子音発音にも影響する。

したがって、

> **C = 意味の骨格**  
> **V = 音韻的な接着剤**  
> **接辞 = 概念操作**  
> **高さ = 形態構造**

という役割分担が、この言語の基本設計となる。

# 18. 現時点での設計の核

この言語の最も重要な特徴は、単に「独特な音がある」「独自文字を使う」ことではない。

**色彩認知から意味体系が生まれ、その意味体系から語彙と文法が発達し、その歴史が文字の二次元構造と現代語の発音にまで残っていること**

を中核とする。

理想的には、未知の単語を見た話者が完全な意味を知らなくても、

- どの原始概念から派生したのか
- どこが語根なのか
- どこが限定要素なのか
- どこが派生操作なのか

をある程度推測できる。

一方で、完全に機械的に意味を復元できる論理記号体系にはせず、歴史的変化・複合・意味拡張・音韻変化による**自然言語的な不透明さ**も残す。

この「意味的には半透明だが、完全には透明ではない」状態を目標とする。

# 19. 文法の現在の方針（2026-10-02）

基本語順は **VO(S)**。動作を先に述べ、対象を続ける。行為者は文脈から読み、必要な場合に副詞的な状況補足として後置する。必須の主語枠として扱わない。

否定は **開始標識＋否定する範囲＋終了標識** で表す。範囲は一語に限らず句・節でもよい。名詞句を挟むと **その名詞句に当てはまるもの以外** を表す。例えば『粥』を挟めば『粥以外のもの』となる。範囲は文脈や周囲の語義で限定する。

開始と終了は別々の機能語として試作する。標識の具体的な音形・文字位置、述語・節の否定の詳細、他の機能語との関係は今後決める。

行為者・受け手などの役割語、目的語の省略条件、人称・時制・疑問・命令・修飾の規則は未決定。詳細は[試作07](drafts/007-vo-and-scoped-negation.md)を参照する。

# 試作04 — 8母音音素と細分化した接辞

作成日：2026-10-02

## 決定事項と試作の境界

ユーザーの決定：母音は /a i e o/、各々の長短を区別する。中位が無声の子音は基本的に高位を有気、低位を有声とする。接辞は細かく作ってよい。m・n・lは無声形を利用する方向だが、三段階の完成形は要検討。

以下の接辞32案（接頭辞4、接尾辞28）は**未採用**。その音形、意味の区切り、語源はユーザーによる吟味の対象。旧試作の語義を維持したまま接辞の意味だけが変更されたとは扱わない。

## 母音と表記

| 試作用表記 | IPA |
|---|---|
| a / aa | /a/・/aː/ |
| i / ii | /i/・/iː/ |
| e / ee | /e/・/eː/ |
| o / oo | /o/・/oː/ |

二重母音字は長母音の暫定的な転写で、二音節とはしない。長母音を強勢の記号や大小・強弱の意味コードにはしない。各接辞の意味は母音と子音を含む形全体に割り当てる。

語根に付ける母音、接続母音、母音連続、強勢、長母音の弱化・脱落の規則は未決定。接辞の長母音は接続母音のように自由に削除しない。長短が語を区別する以上、短化を導入するなら環境と合流する形を記録する。

## 接頭辞4案 — Xの見方を限定する

| 分析形 | 高位の試読 | 意味 | 文法化の筋道（すべて仮説） |
|---|---|---|---|
| aj- | /aç/ | 別系統のX・もう一方のX | 枝の分岐→分かれた別の枝→比較対象と別系統に属するという限定。単純な否定にはしない。 |
| ij- | /iç/ | 元の全体から離れたX | 枝の切り離し→所属から離れているという限定。後述-aajが片を新たに指すのに対し、こちらはX自体の離れた状態を限定する。 |
| aak- | /aːkʰ/ | 密集した・数の多いX | 草の密な群生→対象の数・密度が高いという限定。Xというカテゴリーは変えない。 |
| ek- | /ekʰ/ | まばらな・数の少ないX | 密な群生と疎らな群生を呼び分ける用法から数量の限定へ。少量が短母音に対応する一般規則は作らない。 |

各語源は、独立語から限定要素に変わる構文を今後用例で検証する。母音を変えれば自動的に反対の意味になる規則ではない。

## 接尾辞28案 — 入力の種類と操作を分ける

名詞に付くか、活動・過程に付くかを明記する。例えば道具に『分割』を付けても、その道具で切る意味になるとは限らない。Xを操作対象にする形と、Xを使う行為を指す慣用語を分ける。

### 部分・分割・結果：9案

語源の出発点は枝、分枝、枝を分ける作業、そのあと残る片。各接辞の区別が歴史のどの段階で生まれたかは未設計。特に-aj・-aaj・-ij・-iijを単なる母音の意味分類として説明しない。

| 分析形 | 低位の試読 | 入力 → 出力 | 意味の範囲 |
|---|---|---|---|
| -aj | /aɟ/ | 全体 → 部分の名詞 | Xを構成する一部分。分離したとは限らない。 |
| -aaj | /aːɟ/ | 全体・材料 → 分離片の名詞 | Xから切り離した片。長いから大きいという意味ではない。 |
| -ij | /iɟ/ | 分岐する構造 → 分枝の名詞 | Xの分枝・支系。単なる任意の部分ではない。 |
| -iij | /iːɟ/ | 共同の資源 → 割当分の名詞 | Xのうち一人・一組に割り当てられた分。分配の慣行から部分接辞が特殊化する案。 |
| -ej | /eɟ/ | 分割できる対象 → 動詞 | Xを切り分ける。旧案の『活動一般』から限定し直す案。 |
| -eej | /eːɟ/ | 配分できる対象 → 動詞 | Xを分けて受け手に配る。単なる切断と区別する。 |
| -eek | /eːg/ | 集められる対象 → 動詞 | Xを集める。草を束に集める作業→収集する操作という語源案。 |
| -oj | /oɟ/ | 活動・過程 → 産物の名詞 | Xを行った結果として得るもの。名詞に付けて何でも結果にする形にはしない。 |
| -ooj | /oːɟ/ | 活動・過程 → 残滓の名詞 | Xの後に残る不要物・残り。意図して得た産物と区別する。 |

### 集合・場所：6案

集合は草の群生・採集して束にする作業、場所は空から空間への拡張を出発点にする。結合構造は繊維を撚り、紐を結ぶ作業を介した後代の特殊化とする。

| 分析形 | 低位の試読 | 入力 → 出力 | 意味の範囲 |
|---|---|---|---|
| -ak | /ag/ | 個々のもの → 集合の名詞 | Xのまとまり。互いに繋がっているとは限らない。 |
| -aak | /aːg/ | 結合できる部材 → 構造の名詞 | 複数のXを繋いで作った構造。紐の束と網の違いを表せる候補。 |
| -ik | /ig/ | 束ねられるもの → 一束の名詞 | 運搬・保存・取引で一単位に扱うXの束。散在する集合とは区別。 |
| -al | 低位l未決定 | 対象・活動 → 場所の名詞 | Xを恒常的に置く・行う場所。旧案を引き継ぐ。 |
| -aal | 低位l未決定 | 対象・活動 → 区画の名詞 | Xのために囲い、区切った室・区画。恒常性とは別の属性。 |
| -el | 低位l未決定 | 活動・出来事 → 地点の名詞 | Xが起きた地点。そのために作った設備は含めない。 |

低位lが決まるまで場所接辞のIPAは保留する。旧試作02の /aɭ/ は参照用の仮音であり、ここで確定扱いにしない。

### 道具・容器・材料：4案

石の打ち道具、据えて使う磨り石、窪んだ臼、石材から作る物を中間概念に置く。すべて『石だから道具』という一段の飛躍では説明しない。

| 分析形 | 低位の試読 | 入力 → 出力 | 意味の範囲 |
|---|---|---|---|
| -az | /aʐ/ | 活動 → 道具の名詞 | Xを行う手持ちの道具。対象名詞に付けて用途が自動決定する形ではない。 |
| -aaz | /aːʐ/ | 活動 → 設備の名詞 | Xを行うために据えて使う設備。大きさだけで道具と区別しない。 |
| -iz | /iʐ/ | 内容物 → 容器の名詞 | Xを入れる容器。臼の受け皿から容器という役割が一般化する案。 |
| -oz | /oʐ/ | 材料 → 製品の名詞 | Xで作った物。用途は別途指定する。Xそのものと、Xを材料にした製品を区別。 |

### 流出・担い手：4案

血が身体内にあり、切り傷から外へ出て流れるという観察を媒介にする。担い手は血のある身体→仕事を行う人→行為者という中間段階を要する。この系列の一般化は重点検討事項。

| 分析形 | 低位の試読 | 入力 → 出力 | 意味の範囲 |
|---|---|---|---|
| -ov | /ow/ | 発生源 → 流出物の名詞 | Xから外へ出るもの。液体以外への一般化は語ごとに検討。 |
| -ev | /ew/ | 流れる物質 → 動詞 | Xが流れる。発生源でなく、流れるものを入力にする。 |
| -eev | /eːw/ | 流れる物質 → 動詞 | Xを流す・外へ出す。使役一般に広げない。 |
| -iv | /iw/ | 活動 → 行為者の名詞 | Xを行う生きた担い手。職業・一時的な実行者の区別は後続案。 |

### 支持・摂食：5案

支持は骨が身体を支える観察、枝の骨組みが屋根を支える作業を介して一般化する。摂食は果実を食べ、他者に与える慣行から一般化する。これらも古語の具体的な構文は未設計。

| 分析形 | 低位の試読 | 入力 → 出力 | 意味の範囲 |
|---|---|---|---|
| -ash | /aʒ/ | 支えられる全体 → 支持構造の名詞 | Xを支える骨組み・構造。Xの全体そのものとは区別。 |
| -esh | /eʒ/ | 支えられる対象 → 動詞 | Xを支える。成立させる・正当化する等の抽象義はまだ含めない。 |
| -ach | /adʒ/ | 食べられる材料 → 食物の名詞 | Xを主材料とする食物。調理工程までは指定しない。 |
| -ech | /edʒ/ | 食べられる対象 → 動詞 | Xを食べる。Xを道具として食べる、という意味にはしない。 |
| -eech | /eːdʒ/ | 食べられる対象 → 動詞 | Xを食物として他者に与える。受け手を食べさせるという解釈を避け、Xは食物に固定する。 |

## 既存語彙への適用は次段階

- 旧-ejの『Xに関わる活動』は、この案では分割・分配・収集・流動・支持・摂食などに分けた。単に語尾を置換するのでなく、入力を対象・道具・材料・活動のどれと解釈するかから再評価する。
- 旧-naj-ej『切る』は、ここで-ejを『入力Xを切り分ける』と読むと『刃を分割する』になってしまう。一般的な切断動詞は、刃を使う作業が慣用化する別の語源・構文を設計する必要がある。
- 旧-z-az『槌』も、この案の活動入力の-azだけでは導出できない。石で打つ行為を先に語彙化するか、材料からの道具化を別の接辞・構文にする。
- 網は単なる紐の集合-akより、紐を繋いだ構造-aakで説明しやすくなる。一方、語源的には旧形から意味が定着して残る可能性もある。どちらを採用するかは未決定。
- 語形は細分化した接辞の機能を試す候補であり、語義の系統樹を捨てるものではない。既存JSONは旧試作として残す。

## 次の検証

まず部分・集合・道具・摂食の系列から少数を取り、対象・行為・産物・担い手が混ざらずに語を作れるか試す。接頭辞ではj・kの高位を、接尾辞ではj・k・z・v・sh・chの低位を確認できる。m・n・lと摩擦音の高位の具体的実現は、その結果と分けて検討する。

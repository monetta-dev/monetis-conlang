# 試作05 — 短い生活語を増やす

作成日：2026-10-02  
状態：方針に沿う追加候補。個別の語・接辞・短縮規則は未採用。

**新しい見出し候補90語、既存13見出しの見直し、計103見出し。** 長母音を一音節として数え、1音節42語、2音節42語、3音節19語。単に複合を長くするのでなく、暮らしで繰り返し使う対象・作業を名付けた。

## 長くしないための運用

- 今回は日常の見出し候補を1〜3音節に収める。これは言語全体の上限や音節規則の決定ではない。長母音が多い3音節語も、頻度・言いやすさで見直す。
- 材料・用途・場所・行為者を全部一語へ詰め込まない。詳細な役割や一時的な条件は句・文へ回す。例えば『水場へ行く人々のための果汁入れ』という説明全体を新語にしない。
- 木・道・杭・粥・布など、頻繁に呼ぶ対象を先に選ぶ。同じ接辞を全語へ総当たりで付けない。規則派生の語も、独立して呼び分ける生活場面を記す。
- 原始的な語が複合として定着し、後世に新たな派生の足場になることを許す。派生語が語幹になっても、内部の接辞の高さ・音価は勝手に中位へ戻さない。
- 詳細な語源の構成を記録することと、現代の一語を長くすることを分ける。短縮は音変化の経路を示すか、頻用の意味が慣用的に定着する経路を示す。
- 元の長母音を、短く見せるためだけに短母音へ変えない。新しい語形に/u/・未決定の低位m/n/lは使わない。

## 方針の了承と個別採用

母音・子音系列・細分化する接辞という設計方針に沿って試作を進める。試作04の全接辞や各語形を一括採用されたとは扱わない。旧試作02の広い-ej『活動一般』を、この試作で生産的に使わない。

## 発音用表記

今回の見出し形は、発音を読みやすくするための**暫定的な音価寄りの表記**。旧表の基本字系列を保つ転写とは役割が異なる。独自文字の最終表記ではない。構成と高さは構造化データに別途保持する。

| 表記 | 音価 | 例 |
|---|---|---|
| j / gy | /ʝ/・/ɟ/ | 道 zaj /zaʝ/ と、旧候補の石片を音写したzagy /zaɟ/ |
| k / g | /k/・/g/ | 穀草 chak /tʃak/ と、旧候補の収穫物chag /tʃag/ |
| z / r | /z/・/ʐ/ | 石のz語根と、容器・道具接辞の低位z |
| sh / zh | /ʃ/・/ʒ/ | 骨のsh語根と、支持接辞の低位sh |
| ch / dj | /tʃ/・/dʒ/ | 果実のch語根と、摂食接辞の低位ch |
| v / w | /v/・/w/ | 血のv語根と、流出接辞の低位v |
| aa / ii / ee / oo | /aː iː eː oː/ | 長母音を保持する。短母音との区別を消さない。 |

例えば旧候補の繊維・紐をここで音写するなら **kagy /kaɟ/**・**kagyag /kaɟag/**。それを繋いだ平面構造としての布は **kagyaag /kaɟaːg/**。紐と布で母音長が違うが、長母音一般が『平面』『大きい』を意味する規則ではない。

## 短縮規則の候補と途中の形

どちらも未採用の歴史案。現在語の話者がその場で好きな母音を省く規則ではない。

### W1：低位vの弱化と母音融合

この古い語の系列では、低位vに由来する/w/が/o_a/で落ち、その後/o+a/が/oː/へ合流したと仮定する。

- 水：/lamowag/ → /lamoag/ → **/lamoːg/**。
- 滴：/lamowaɟ/ → /lamoaɟ/ → **/lamoːɟ/**。

二つの語と、その短縮語幹を使う派生に適用する。/w/一般を落とす規則にはせず、/θow/『香り』の語末wや/lamoːgew/『水が流れる』の語末wは保持する。旧辞書全体へのW1の適用・例外・表記上の無音字の扱いは未検証。

### C1：古い名詞複合の接続母音脱落

寝敷き＋身体、短縮した水＋骨組みという古い複合では、接続の/a/が無強勢で、破裂音の後に次の語幹が来る環境で落ちたと仮定する。

- 寝床：/jak-a-vat/ → **/jakvat/**。
- 橋：/lamoːg-a-ʃaʝ/ → **/lamoːgʃaʝ/**。

今回試す連続は/k.v/と/g.ʃ/。語根内母音・接辞の初頭母音・長母音には適用しない。特に-akと-aakの違いを潰さない。強勢体系・音節境界・音声的な実現はこの仮説に合わせて次に検討する。全語へ無条件に適用して子音を連ねない。

## 追加の接辞2案

液体を口に取り入れる行為を、固形の食物を食べる-echと分けるための候補。旧『水に関わる活動』から飲む意味を恣意的に選ばず、入力と動作を指定する。

| 分析形 | 低位の試読 | 入力 → 出力 | 語源の筋道 |
|---|---|---|---|
| -ich | /idʒ/ | 飲める液体 → 動詞『Xを飲む』 | 果汁をすすって摂取する構文→液体の摂取という機能が食べる形から分化する案。 |
| -iich | /iːdʒ/ | 飲める液体 → 動詞『Xを他者に飲料として与える』 | 飲料を与える慣行から供与形が定着する案。 |

古語形と具体的な構文は未設計。iを液体一般、長母音を使役一般の意味コードにはしない。

## 語義の幅と句に回すもの

担ぎ棒・道・寝床には、反復される行為を短く呼ぶ慣用的な動詞用法も提案した。全ての名詞を無条件に『それをする』という動詞へ変換する規則ではない。動詞用法の項構造、名詞との統語上の区別、品詞標識は未決定。

『寝床へ横たわる』から睡眠状態を自動的に導かない。眠る、目を閉じる、起きる等は今後別に作る。身体・生き物・人の呼称も、全てを『血』から一段で抽象化しない。

『同じ炉で暮らす人々の分け前を記録する係』『穀粒を運ぶ人々のための布袋』などは、役割を説明する句として設計する対象に残す。今回それぞれを長い一語にはしていない。句の人工言語での語順や格標識は未設計であり、日本語の説明を人工言語の完成文として扱わない。
